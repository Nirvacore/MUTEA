## แบบที่ 1 — อีเมล (ฉบับเต็ม)

> **หัวข้อ:** สอบถามบริการ OEM ชาสมุนไพร — แบรนด์ Mu Tea

เรียน ทีมงาน [ชื่อบริษัท]

สวัสดีค่ะ ดิฉัน [ชื่อ] กำลังเตรียมเปิดแบรนด์ชาชื่อ **Mu Tea** ค่ะ

Mu Tea เป็นแบรนด์ชาที่เน้นเรื่องการใช้ชีวิตอย่างช้าลงและการอยู่กับปัจจุบัน กลุ่มลูกค้าหลักคือผู้หญิงวัยทำงาน 28-55 ปี ที่มองหาช่วงเวลาสงบในแต่ละวัน เราวางแผนเริ่มจากชาสมุนไพรไทยแบบไม่มีคาเฟอีนก่อน เพราะเหมาะกับการดื่มช่วงเย็นซึ่งเป็นช่วงเวลาที่แบรนด์เราให้ความสำคัญค่ะ

<!-- TODO: ย่อหน้า "ทำไมถึงทำแบรนด์นี้" — ดูหมายเหตุด้านล่าง -->

ตอนนี้อยู่ในขั้นตอนหาโรงงานผู้ผลิต จึงอยากขอสอบถามข้อมูลเบื้องต้นดังนี้ค่ะ

1. **MOQ** สำหรับสูตรชาสมุนไพรแบบ custom — ทั้งแบบซองชา (tea bag) และแบบใบชา (loose leaf) ขั้นต่ำเท่าไหร่คะ
2. ทางโรงงาน**รับดำเนินการจดทะเบียน อย.** ให้ภายใต้แบรนด์ของเราด้วยหรือไม่ และมีค่าใช้จ่ายเท่าไหร่คะ
3. เราสามารถ**ออกแบบสูตรผสมเอง** (เช่น ตะไคร้ + ใบเตย + อัญชัน ในอัตราส่วนที่กำหนดเอง) ได้หรือไม่ หรือต้องเลือกจากสูตรที่มีอยู่แล้วคะ
4. มี**วัตถุดิบออร์แกนิก**ที่มีใบรับรองให้เลือกหรือไม่คะ
5. **รูปแบบบรรจุภัณฑ์**ที่มีให้เลือก (ซองพีระมิด / ถุงฟอยล์ซิปล็อค / กระปุก) และ MOQ ของแต่ละแบบค่ะ
6. **ระยะเวลา**ตั้งแต่อนุมัติสูตรจนได้สินค้าพร้อมขาย ประมาณกี่สัปดาห์คะ
7. **ราคาต่อหน่วย**โดยประมาณ ที่จำนวน 100 / 300 / 500 ชิ้น ค่ะ

นอกจากนี้ หากทางโรงงานมี**ชุดตัวอย่าง (sample kit)** ให้ทดลองชิม รบกวนแจ้งเงื่อนไขและค่าใช้จ่ายด้วยนะคะ ดิฉันยินดีชำระค่าตัวอย่างค่ะ

## แบบที่ 2 — LINE / Facebook (ฉบับสั้น)

> ใช้กับเจ้าที่ช่องทางหลักคือ LINE OA หรือเพจ (เช่น Chiangmai Tea)

สวัสดีค่ะ สนใจบริการ OEM ชาสมุนไพรค่ะ

กำลังเตรียมเปิดแบรนด์ชาชื่อ Mu Tea เน้นชาสมุนไพรไทยไม่มีคาเฟอีน สำหรับดื่มช่วงเย็นค่ะ ตอนนี้กำลังหาโรงงานผลิต

## สัญญาณอันตราย (ถ้าเจอ ให้ระวัง)

| สัญญาณ | แปลว่า |
|--------|--------|
| เลี่ยงไม่ตอบเรื่อง MOQ ตรงๆ | อาจสูงกว่าที่เรารับไหว แล้วจะมาบอกทีหลัง |
| ไม่มีเอกสาร GMP/HACCP ให้ดู | ความเสี่ยงเรื่องคุณภาพและการจด อย. |
| เสนอสูตร "ลดน้ำหนัก / ดีท็อกซ์ / เพิ่มภูมิ" ให้ | โรงงานคุ้นกับการเคลม — **เราต้องอยู่เลนอาหารทั่วไป** (Report 011) |
| บอกว่าจดเป็น "ผลิตภัณฑ์สมุนไพร" ง่ายกว่า | คนละ track กัน หนักกว่า ช้ากว่า — **เรายืนยันเลนอาหารทั่วไป** |
| ไม่ยอมให้ชิมตัวอย่างก่อนสั่งจริง | ห้ามสั่งเด็ดขาด |

## หลังได้คำตอบครบ → ทำอะไรต่อ

1. กรอกตารางเปรียบเทียบ
2. สั่งชุดตัวอย่างจาก **2 เจ้า**ที่ดูดีที่สุด (อย่าสั่งเจ้าเดียว — ไม่มีอะไรเทียบ)
3. ชิมจริง — จดบันทึกกลิ่น รสก่อน กลางลิ้น รสตาม ความรู้สึกหลังดื่ม
4. เลือก 1 เจ้า → คุยเรื่องสูตร signature
5. อนุมัติสูตร → โรงงานจด อย. → ออกแบบบรรจุภัณฑ์ → ผลิต

**Timeline ประมาณ 10-12 สัปดาห์จนขายได้ครั้งแรก** (Report 011)

## หมายเหตุ: ย่อหน้าที่ต้องเขียนเอง

ในอีเมลมี `<!-- TODO -->` อยู่หนึ่งจุด — ย่อหน้า **"ทำไมถึงทำแบรนด์นี้"** (ประมาณ 3-4 บรรทัด)

ผมเว้นไว้ให้เขียนเองเพราะนี่เป็นส่วนเดียวที่ผมเขียนแทนไม่ได้จริงๆ ครับ

**ทำไมย่อหน้านี้ถึงสำคัญกับโรงงาน:** โรงงาน OEM เจอคน "อยากมีแบรนด์ชา" สัปดาห์ละหลายราย ส่วนใหญ่หายไปหลังได้ใบเสนอราคา เขาเลยอ่านอีเมลเพื่อหาคำตอบว่า *คนนี้จะอยู่ยาวไหม* ย่อหน้าที่มีเหตุผลส่วนตัวชัดเจนคือสัญญาณว่าเราไม่ใช่คนที่จะหายไป — และมันเปลี่ยนจาก "ขอใบเสนอราคา" เป็น "เขานั่งคุยเรื่องสูตรกับเรา"

**ควรมีอะไรบ้าง:**
- เรื่องนี้เริ่มจากอะไร (ประสบการณ์ส่วนตัว / ช่วงเวลาที่ชาช่วยเรา)
- ทำไมต้องสมุนไพรไทย ไม่ใช่แค่ชานำเข้า
- เราจริงจังแค่ไหน (ทำรีเสิร์ชมาแล้ว วางแผนระยะยาว)

**ข้อควรระวัง:** อย่าเขียนแบบ marketing — โรงงานอ่านออกทันที เขียนแบบเล่าให้คนแปลกหน้าฟังตรงๆ ดีกว่า

**ตัวอย่างโทนที่ใช้ได้ (เขียนใหม่ด้วยเรื่องจริงของตัวเอง):**

> จุดเริ่มต้นมาจากช่วงที่ทำงานหนักมากจนนอนไม่หลับ แล้วมาเจอว่าการต้มชาสมุนไพรตอนเย็นทำให้ได้หยุดจริงๆ วันละสิบนาที เลยอยากทำแบรนด์ที่ขายช่วงเวลานั้น ไม่ใช่แค่ขายชา ตอนนี้ศึกษาเรื่องวัตถุดิบและกฎระเบียบมาพอสมควรแล้ว และตั้งใจทำระยะยาวค่ะ
