# MU Universe Handoff

**Date:** 2026-10-17  
**Purpose:** Reframe the existing MUTEA research under the wider MU Universe without losing the tea work already done.

## Canonical relationship

- **MU Universe** = botanical living world / product-and-knowledge venture.
- **MUTEA** = tea branch inside MU Universe.
- **Nirva** = shared operating, AI, knowledge, work, commerce, trust, and communication capabilities.

## Preserve

Keep all existing tea research and especially `docs/research/012-global-botanical-atlas.md`.

That report already contains the core long-term direction:
- multi-format botanical house;
- global bioregion knowledge;
- format honesty;
- direct sales;
- no MLM;
- no unsupported health claims.

## Expand carefully

MU Universe can later include:
- whole dried botanicals;
- cut botanicals;
- powders;
- spices;
- simple blends;
- tea when suitable;
- other formats only when evidence, process, regulation, and demand justify them.

Powder is important but is not the universal default.

## Core data model

Material → Source → Supplier → Lot → Process → Test → Regulatory class → Allowed claims → SKU → Knowledge card

## User language

Use simple action words:

**Eat · Cook · Drink · Home · Body · Store · Avoid · Learn**

Do not imply that every material is suitable for every lane.

## Truth model

Separate:
- Known
- Traditional
- Evidence
- Approved
- Unknown

Never turn traditional use into a medical claim by implication.

## Nirva reuse

Do not build duplicate business systems inside MUTEA/MU Universe.

Reuse where appropriate:
- Nirva Buy
- Nirva Sell
- Nirva Library
- Nirva AI
- Nirva Work
- Nirva Connect
- Nirva Trust

## AI taxonomy correction

`MU UNIVERSE` is a venture/product world, not an agent category. The legacy grouping in `nirva-AI` should be migrated separately to capability categories after the current agent-registry work is stable.
